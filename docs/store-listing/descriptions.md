## Descripción completa (máx. 4000 caracteres)

```
EPSEA es la aplicación móvil oficial para extensionistas de la Escuela de Producción y Sostenibilidad Agroalimentaria (EPSEA) de la Universidad de Córdoba.

Permite registrar y dar seguimiento a visitas técnicas a productores agroalimentarios, completar encuestas estructuradas, adjuntar fotografías de campo y sincronizar la información con el sistema central — incluso con conectividad limitada.

Funcionalidades principales:
• Inicio de sesión seguro para extensionistas autorizados
• Consulta de proyectos y productores asignados
• Registro de visitas técnicas (Visitas 1, 2 y 3)
• Encuestas de caracterización, información personal, predio y líneas productivas
• Captura de fotos desde cámara o galería
• Sincronización de datos con el servidor EPSEA
• Modo offline: trabajo en campo sin conexión continua
• Notificación de progreso durante sincronizaciones prolongadas

Requisitos:
• Cuenta de extensionista EPSEA activa
• Conexión a internet para la sincronización inicial y envío de datos

Esta aplicación está destinada al personal de extensión y acompañamiento técnico del programa EPSEA. No es una app de consumo general.

Desarrollado para la Universidad de Córdoba — EPSEA.
```
